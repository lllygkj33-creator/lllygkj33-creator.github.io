> Discord 要先认清一件事：**服务器里的内容基本进不了搜索引擎**。它不产生 SEO 收益，价值在于留存、信任和素材——把它当获客渠道会失望。

## 为什么它不算 SEO 渠道

- **内容不被索引**：服务器内的消息是登录后才能看的，爬虫拿不到，Google 里搜不到
- **邀请链接不传权重**：外链是 `nofollow`
- **公开服务器的 Server Discovery** 有曝光，但那更像平台内的目录，不是搜索流量

所以 Discord 的作用和三件事有关：**留住核心读者、收集真实问题、建立信任**。

## 那它值不值得做

值得，但要摆对位置：

| 它能做 | 它不能做 |
| --- | --- |
| 留住反复访问的读者 | 带来搜索排名 |
| 收集真实问题（转成选题） | 直接带来陌生流量 |
| 发布前的反馈池 | 替代社媒扩散 |
| 建立"人"的信任 | 替代站点内容 |

## 怎么做

1. **人少的时候不要建**：没有稳定读者，服务器就是空房间。有 50-100 个愿意互动的人再开
2. **频道按问题分**：不要按话题命名，按读者会问的问题命名（"抓取问题""工具推荐"）
3. **把讨论沉淀出去**：频道里被反复问的问题，整理成站内文章，再回来贴链接——这就是把社区讨论变成站点内容的闭环
4. **邀请链接用永久链接**，临时链接会过期，放在站内和资料页里会失效
5. **站内给一个入口**：文章结尾或"关于"页放服务器入口，让它有机会被找到

> 提示：Discord 的正确用法是"把已有的读者留下来"，而不是"把不知道你的人拉进来"。拉新在 Reddit / YouTube / X，留存在这里。

## 判断有没有起作用

- 服务器里的问题，有多少变成了你的文章选题
- 站内文章发布后，有没有人先在服务器里讨论再出去分享
- 成员里有多少是从站内点进来的（用带 UTM 的邀请链接能区分）

## Next steps

- 把社区讨论变成站点内容：Discord 是最好用的问题来源
- Medium：另一个"有平台权重但要小心用法"的渠道
