> 模型分两层：**打分层**给出各维度分数与优缺点，**规则层**在打分之后强制封顶。第二层是这套体系最硬的部分，因为它可计算、可复现。

## 加权公式

```text
内容质量总分 = E-E-A-T × 0.40 + 有用内容 × 0.35 + 信息增益 × 0.25
E-E-A-T     = (第一手经验 + 专业性 + 权威性 + 信任度) ÷ 4
```

各维度满分 10 分，所有单项先打分再加权。

| 维度 | 权重 | 核心问题 |
| --- | ---: | --- |
| E-E-A-T（四维均值） | 40% | 这篇内容凭什么可信 |
| 有用内容 | 35% | 读者能不能快速拿到价值 |
| 信息增益 | 25% | 比现有资料多说了什么 |
| YMYL 风险 | 不参与加权 | 有没有触红线，单独作为风险卡 |

**YMYL 为什么不算总分**：它是条件型维度。一篇普通产品评测根本用不到它，硬加权进去只会稀释其他维度的差异。它单独以风险等级呈现（低 / 中 / 高）。

## 分档标准

| 分数 | 档位 | 含义 |
| ---: | --- | --- |
| ≥ 8.5 | 绿 | 该维度没有明显扣分点 |
| 7.0 – 8.5 | 橙 | 可用，但有明确改进空间 |
| < 7.0 | 红 | 触发熔断，或存在结构性缺陷 |

分档阈值是界面内部划分，不是平台标准。

## 熔断规则

熔断在打分之后执行，**触发即封顶，不看文笔**。全局规则：

| 触发条件 | 结果 |
| --- | --- |
| 出现绝对化营销词（如 game-changer、unprecedented、revolutionary、the ultimate、gold standard） | 封顶 **7.5** |
| 高危内容且全文无免责声明（硬件行业：私有 Tracker、DRM 规避、破解；视频与 AI 工具行业：真人肖像未授权、AI 生成未标注） | 熔断 **5.5** |
| 内链密度 > 1.5 个/百字 | 封顶 **7.5** |
| 外部权威来源为 0 | 封顶 **7.5** |
| 数据断言 ≥ 3 处但外部链接为 0 | 封顶 **7.0** |

后两条是可计算的——直接从正文统计得出，不依赖模型判断：

```text
外链数 = 指向站外权威来源的链接数
数据断言数 = 匹配 \d+(%|x|GHz|MB/s|TB) 一类表达的处数

if 外链数 == 0 and 分数 > 7.5:            分数 = 7.5
if 数据断言数 >= 3 and 外链数 == 0:       分数 = 7.0
```

### 各维度封顶速查

| 维度 | 触发 | 封顶 |
| --- | --- | ---: |
| 第一手经验 | 提出具体结论但无一手测试痕迹 | 7.5 |
| 专业性 | 涉及高级配置却无可复制的配置块 | 7.0 |
| 专业性 | 宣称高阶能力却不提性能门槛或兼容限制 | 8.0 |
| 权威性 | 给出精准性能数据但未说明测试方法 | 7.5 |
| 权威性 | 基础参数写错 | 5.0 |
| 信任度 | 出现硬数值但缺测试口径 | 6.5 |
| 信任度 | 推销自有产品而无利益披露 | 7.0 |
| 有用内容 | 盘点类内容缺明确决策指引 | 8.0 |
| 有用内容 | 开篇超 100 字无信息背景，或生硬插入无关链接 | 7.5 |
| YMYL | 大量无来源硬数值用于证明产品性能 | 6.0 |
| YMYL | 破坏性操作指令且无前置警告 | 5.0 |
| 信息增益 | 给出性能结论但无可复现方法或独立来源 | 8.0 |
| 信息增益 | 核心主张依赖厂商宣传语 | 7.0 |

## 维度标准要点

| 维度 | 高分表现 | 常见失分 |
| --- | --- | --- |
| 第一手经验 | 有过程、有失败、有对照，数字对得上场景 | 通篇转述，找不到一手痕迹 |
| 专业性 | 讲清适用前提、兼容限制与代价 | 用绝对化词汇代替量化参数 |
| 权威性 | 数据可复核、多方来源交叉验证 | 只引自家口径，或参数写错 |
| 信任度 | 披露清晰、来源可查、语气克制 | 假精确、隐性带货 |
| 有用内容 | 秒答 + 决策清晰 + 结构可跳读 | 开篇铺垫、结论难找 |
| YMYL | 高危操作有护栏，敏感话题有合规声明 | 无免责、无授权说明 |
| 信息增益 | 有原创数据或新框架 | 与现有结果高度重合 |

每个维度的完整评分标准见左侧「维度」分组下的对应页面。

> 所有得分都是**内部诊断模型**，不是任何搜索平台的官方评分。
