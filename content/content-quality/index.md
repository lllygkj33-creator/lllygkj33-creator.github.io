> 内容质量评估回答一个问题：**这篇文章能不能信、值不值得排上去。** 它由三个部分构成：模型定义怎么打分，规范定义怎么标注，实例把真实文章完整拆一遍。

## 它怎么工作

七个维度各自出分，再按固定权重合成一个总览分数；同时有一层**不由模型决定的熔断规则**在打分之后强制改分——模型会松口，规则不会。

| 层次 | 作用 | 谁决定 |
| --- | --- | --- |
| 七维打分 | 给出各维度的分数与优缺点 | 评估模型 |
| 加权汇总 | 给出一个总览印象 | 固定公式 |
| 熔断规则 | 触发即封顶，不看文笔 | 确定性判断 |
| 正文批注 | 指到具体段落，说明为什么扣分 | 批注规范 |

## 七个维度

| 维度 | 看什么 |
| --- | --- |
| 第一手经验 | 有没有真实上手、测试、踩坑的痕迹 |
| 专业性 | 技术严谨性、边界界定、权衡 |
| 权威性 | 结论可不可复核、有没有多方来源 |
| 信任度 | 诚实度、利益透明度、安全底线 |
| 有用内容 | 到达价值的时间、决策效率 |
| YMYL 风险 | 会不会让人损失钱、触犯法规、丢数据 |
| 信息增益 | 相对现有资料多出来的增量价值 |

每个维度的加分项、扣分项、分档与熔断规则各自成页，见下方栏目结构。

## 分档怎么看

所有维度共用一套分档：**≥ 8.5 绿（没有明显扣分点）、7.0–8.5 橙（可用但有改进空间）、< 7.0 红（触发熔断或存在结构性缺陷）**。

总览页用分档卡呈现：一枚总分卡 + 四枚维度卡，其中 **YMYL 作为风险卡单独展示，不参与加权**——它是条件型维度，普通内容用不到，硬算会稀释其他维度。

权重、公式与全部熔断规则见评分模型。

## 栏目结构

| 页面 | 作用 |
| --- | --- |
| 本页 | 方法总览、七个维度索引与实例清单 |
| 评分模型 | 维度权重、加权公式、分档标准与熔断规则 |
| 批注规范 | 批注字段、维度标签、严重度，以及固定检查位 |
| 维度 | 七个维度各自的评分标准，每维一页 |
| 实例 | 真实文章的完整拆解，每篇一页 |

### 实例清单

| 实例 | 样本行业 | 总分 | 主要问题 |
| --- | --- | ---: | --- |
| 示例 001 | 硬件评测 | 6.84 | 有实测但缺口径，触及合规红线 |
| 示例 002 | 视频创作工具 | 6.53 | 通顺但零证据，缺 AI 披露与授权说明 |

**判断逻辑不随行业变**：只要是可能让人损失钱、触犯法规或毁掉信誉的做法，就进 YMYL。变的是红线内容——硬件行业看版权与数据安全，视频与 AI 工具行业看肖像授权、AI 生成标注与素材商用授权。

## 免责声明

- 所有得分与扣分都是**内部诊断模型**，不是任何搜索平台的官方评分
- 分档阈值是界面内部划分，不是平台标准
- 分数用于排序与定位问题，不预测排名，也不承诺结果
