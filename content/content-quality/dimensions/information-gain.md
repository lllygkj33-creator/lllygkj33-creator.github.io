> 信息增益问的是：**这篇比现有结果多说了什么？** 如果只是把已有信息重新组织一遍，排版再好，增益依然是零。

## 四类增益

| 类型 | 说明 |
| --- | --- |
| 数据型 | 原创测试、统计数据、实验结果 |
| 结构型 | 新框架、新分类、新决策模型 |
| 场景型 | 把抽象参数映射到真实使用场景 |
| 证据型 | 原始截图、案例、限制条件 |

## 四档评级

| 等级 | 含义 |
| --- | --- |
| 3 | 有明显原创证据或高价值新框架 |
| 2 | 有明确的新结构或新解释 |
| 1 | 有少量整理，但新信息有限 |
| 0 | 基本无增益，几乎是重写 |

## 加分项

- **一手证据**：原始数据、复现步骤、完整口径
- **降维整合**：把散落各处的信息整理成能用的框架
- **指出边界**：说明结论在什么条件下不成立

## 扣分项

- **营销同质化**：核心主张依赖厂商宣传语，没有独立见解
- **数据无源**：给出一堆精确数字却没有来源
- **同义改写**：把别人的结论换个说法，信息量没有增加
- **靠篇幅充数**：用背景介绍和总结把字数堆上去

## 分档

| 分数 | 档位 | 特征 |
| --- | --- | --- |
| 9.0 – 10.0 | 行业新知 | 有原创数据或新框架，别人写这个题目必然要引用 |
| 7.5 – 8.9 | 高价值整合 | 结构清晰、有增量视角，但缺一手数据 |
| 6.0 – 7.4 | 增量有限 | 信息正确，但与现有结果高度重合 |
| < 6.0 | 无增益 | 通篇同义改写或厂商口径 |

## 熔断规则

- **一手数据缺失**：给出具体性能或硬件结论，但没有可复现的测试方法或独立来源，**封顶 8.0**
- **营销同质化**：核心主张高度依赖厂商宣传语，**封顶 7.0**
- **外部链接为 0**：全文没有任何外部权威来源，**封顶 7.5**
- **假精确**：数据断言 ≥ 3 处却没有任何外链支撑，**封顶 7.0**

后两条来自审计系统的硬规则——它们是**可计算的**，不依赖模型判断：

```text
ext = 文章中指向站外的链接数
data = 匹配 \d+(%|x|GHz|MB/s|TB) 的断言数
if ext == 0 and score > 7.5: score = 7.5
if data >= 3 and ext == 0 and score > 7.0: score = 7.0
```

## 怎么补

1. 做一次最小实测，哪怕只测一个指标
2. 把过程里的数字原样贴出来，并写清口径
3. 补 2-3 条外部权威来源，形成证据链
