> 摩天大楼优化不是"比别人写得更长"，而是**用同一套维度给目标页和竞品打分，找出差距的具体位置，再按优先级逐条改造**。

这一栏是一整套方法，由模型、规范和实例三部分构成：模型定义怎么打分，规范定义怎么标注，实例把同一篇页面完整拆一遍。

## 它回答什么问题

```text
目标关键词
→ 当前搜索结果竞争格局
→ 目标页得分
→ 与竞品的差距
→ 正文具体哪一段有问题
→ 改造方案与顺序
```

阅读路径是固定的：**先知道差多少，再知道差在哪里，再看正文哪里有问题，最后知道该动什么。**

## 它是什么，不是什么

| 是 | 不是 |
| --- | --- |
| 静态的诊断界面 | 实时抓取工具 |
| 内部评分模型 | 搜索平台的官方排名分 |
| 逐段定位问题 | 自动改写正文 |
| 按优先级排改造顺序 | 排名预测 |

第一版不做：实时抓取搜索结果、自动爬取竞品、自动排名预测、动态编辑器、拖拽交互、依赖动画的图表。

> **内部评估模型，非任何搜索平台的官方排名分。**

## 界面怎么读

1. **总览**：现在强不强、和最强竞品差多少、最优先的问题是什么
2. **对比**：七个维度的形状比总分更重要——哪一格是红的，问题就在那里
3. **正文分析**：每条批注都指到具体段落，说明为什么扣分、怎么改
4. **改造计划与优先级**：从 P0 开始，一次改一类，改完留基线

具体怎么算分见评分模型，怎么标注见批注规范，完整效果见示例 001。
