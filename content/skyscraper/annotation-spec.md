> 批注是整页最重要的视觉模块：**左边是目标页正文，右边是对应段落的问题卡片**。规范不统一，实例之间就没法比较。

## 布局规范

| 屏幕 | 布局 |
| --- | --- |
| 桌面 | 左 65% 正文 / 右 35% 批注 |
| 平板 | 左 60% / 右 40% |
| 手机 | 正文 ↓ 批注，按段落顺序堆叠 |

一张正文卡片只放被标注的那一段或那一句，右侧批注卡与之水平对齐。**不做截图叠层和箭头指向**——改一个字就错位，而且无法搜索复制。

## 七类批注标签

标签与评分维度一一对应，用中文：

| 标签 | 对应维度 | 含义 |
| --- | --- | --- |
| 意图 | 意图匹配 | 意图不匹配 |
| 覆盖 | 覆盖度 | 必要问题缺失 |
| 深度 | 深度 | 解释过浅 |
| 增益 | 信息增益 | 信息增益不足 |
| 证据 | 证据与 E-E-A-T | 缺证据 |
| 时效 | 时效 | 已过期 |
| 结构 | 结构与体验 | 信息组织问题 |

## 三档严重度

| 严重度 | 判定 |
| --- | --- |
| 高 | 明显错误、高风险、误导性强——不改不能上线 |
| 中 | 信息或证据不足、结构不佳 |
| 低 | 表达优化、细节补强 |

## 一条批注的六个字段

| 字段 | 说明 |
| --- | --- |
| 标签 | 上面七类之一 |
| 严重度 | 高 / 中 / 低 |
| 扣分 | 该问题造成的影响，如 增益 −6 |
| 问题 | 一句话说清犯的是什么 |
| 原因 | 为什么扣分，指到具体标准 |
| 改法 | 可执行的修改方向 |

扣分是**内部诊断口径**，用于排序，不是平台打分。

## 内容差距分类

正文批注汇总成五类差距，用来给整页定问题结构：

| 差距 | 含义 |
| --- | --- |
| 缺失 | 缺关键子问题 |
| 过浅 | 已覆盖但过浅 |
| 同质 | 与结果页已有内容重复 |
| 过期 | 信息已失效 |
| 无据 | 主张没有证据 |

**不用"字数比竞品少多少"当差距指标**——篇幅不等于价值。

## 改造优先级模型

```text
优先级 = 影响 × 差距 × 确定度 ÷ 成本
```

四个变量统一按 1–5 打分：

| 变量 | 含义 |
| --- | --- |
| 影响 | 对用户与页面价值的提升 |
| 差距 | 与结果页最好水平的差距 |
| 确定度 | 判断的确定程度 |
| 成本 | 执行成本（分母） |

| 等级 | 含义 |
| --- | --- |
| P0 | 立即修 |
| P1 | 高影响 |
| P2 | 增强 |
| P3 | 实验 |

> **内部排序公式**，不是任何平台的排名公式。改造计划里不出现"做完必进前三"这类承诺。

## 术语对照

界面用中文，以下为需要保留英文的专有名词：

| 界面用词 | 保留英文的原词 | 说明 |
| --- | --- | --- |
| 搜索结果 | SERP | 行业标准叫法 |
| E-E-A-T | E-E-A-T | 搜索质量评估框架的固定名称 |
| — | media server software | 目标关键词本身，必须原文 |
| — | xxxx.com/... | 脱敏后的地址占位 |
| P0–P3 | P0–P3 | 优先级等级标识 |

正文引用他人原文时保留原句语言，不做翻译——**原句与专有名词是界面里仅有的英文来源。**
