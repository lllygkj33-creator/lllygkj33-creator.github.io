> YMYL 的核心不是“某几个行业不能做 SEO”，而是：**当错误信息可能给用户或社会造成明显伤害时，页面需要更高等级的准确性、专业性和可信度。**

YMYL 是：

```text
Your Money or Your Life
```

它不是一个独立算法，也不是一个简单的：

```text
医疗 = YMYL
其他 = 非 YMYL
```

的二元分类。

更准确的理解是一个风险梯度：

> **错误信息造成的潜在伤害越大，页面需要的 E-E-A-T 越强。**

## 四类核心风险

Google 质量体系通常重点关注会明显影响这些领域的内容：

| 风险领域 | 常见内容 |
| --- | --- |
| 健康 | 疾病、药物、治疗、营养、心理健康 |
| 财务稳定 | 投资、贷款、税务、保险、退休 |
| 安全 | 电气、危险操作、交通、应急 |
| 社会福祉 | 公民程序、公共事务、重大社会信息 |

此外，一些重要人生决定也可能具有 YMYL 属性：

- 法律
- 就业
- 教育选择
- 住房
- 重大购买
- 儿童安全

关键不是行业名称。

关键是：

> **用户如果相信错误答案，会不会产生严重现实后果。**

## 风险不是二元的

例如：

```text
“咖啡怎么冲”
```

通常不是 YMYL。

但：

```text
“孕妇每天喝多少咖啡因安全”
```

就涉及健康风险。

再例如：

```text
“怎么换键盘轴体”
```

风险低。

但：

```text
“如何自行维修家庭 220V 电路”
```

风险明显更高。

所以判断 YMYL 要看：

```text
主题
+
具体 Query
+
用户可能采取的行动
+
错误后果
```

## 一个风险判断模型

内部可以先做四问。

| 问题 | 是 = 风险上升 |
| --- | --- |
| 错误答案会不会伤害身体 | 是 |
| 会不会造成较大经济损失 | 是 |
| 会不会导致危险操作 | 是 |
| 会不会影响重要法律 / 公民权益 | 是 |

再加两个放大器：

```text
用户是否可能直接按页面执行
是否属于弱势 / 高风险人群
```

例如：

```text
儿童
孕妇
老人
患者
负债人群
```

通常需要更严格边界。

## 健康类

健康是最典型的 YMYL。

### 高风险内容

| 类型 | 示例 |
| --- | --- |
| 诊断 | “这些症状就是糖尿病” |
| 治疗 | “这种方法可以治愈” |
| 药物 | 剂量、停药、相互作用 |
| 心理健康 | 自伤、危机、治疗建议 |
| 营养治疗 | 用饮食替代标准治疗 |
| 儿童健康 | 发育、药物、急症 |

### 红线

避免：

```text
保证治愈
自我诊断
鼓励停药
无依据推荐处方级方案
隐藏严重危险信号
把个例写成医学结论
```

### 需要的信号

- 专业作者或审阅者
- 高质量医疗来源
- 更新时间
- 风险边界
- 危险信号
- 必要时建议就医
- 不夸大证据等级

## 金融类

金融内容的风险在于：

```text
用户可能直接损失钱
```

高风险主题包括：

- 投资建议
- 债务
- 贷款
- 信用
- 退休
- 税务
- 保险

### 红线

| 风险行为 | 问题 |
| --- | --- |
| 保证收益 | 不现实 |
| 隐藏本金风险 | 误导 |
| 个股强推无披露 | 利益冲突 |
| 把历史收益当未来保证 | 错误推论 |
| 无资格给个体税务结论 | 专业边界 |
| Affiliate 不披露 | Trust 问题 |

更合理：

```text
解释机制
+
说明假设
+
展示风险
+
提供来源
+
区分一般信息和个体建议
```

## 法律类

法律内容很容易因为：

```text
国家
州
时间
事实细节
```

不同而改变结论。

### 红线

- 把一般法律信息写成个案确定结论
- 不注明司法辖区
- 使用过时法规
- 无来源解释重大法律责任
- 把模板当成专业法律意见

内容最好明确：

```text
适用地区
更新时间
信息性质
专业来源
何时需要律师
```

## 安全类

安全相关页面包括：

- 电路
- 燃气
- 高压设备
- 汽车维修
- 电池
- 危险化学品
- 高空作业
- 应急处理

最大风险是：

> **用户可能直接照着步骤做。**

所以文章不能只追求“可执行”。

还必须明确：

```text
危险级别
停止条件
专业人员边界
必要防护
不确定时不要继续
```

## 电商也可能进入 YMYL

普通手机壳不属于典型 YMYL。

但产品品类变化后风险不同。

| 品类 | 风险 |
| --- | --- |
| 手机壳 | 低 |
| 显示器 | 低到中 |
| 儿童安全座椅 | 高 |
| 医疗器械 | 高 |
| 保健品 | 高 |
| 家用电气设备 | 中到高 |
| 防护装备 | 高 |
| 金融服务 | 高 |

所以电商 SEO 不能用同一套内容标准覆盖所有 Collection。

## 保健品红线

这是非常常见的高风险品类。

危险内容包括：

```text
治愈疾病
替代药物
保证减肥
保证激素变化
使用未经支持的医学 Claim
```

更合理：

| 内容 | 做法 |
| --- | --- |
| 成分 | 描述已知性质 |
| 证据 | 标明研究等级 |
| 效果 | 避免保证 |
| 用量 | 依据正规来源 |
| 风险 | 写清禁忌和相互作用 |
| 审阅 | 专业健康审阅 |

## 儿童品类红线

儿童安全相关产品比普通消费品要求更高。

例如：

```text
儿童座椅
婴儿床
玩具安全
喂养产品
```

不应该只写：

```text
Best
Top
Safest
```

而没有：

- 标准
- 测试依据
- 年龄 / 体重条件
- 安装要求
- 安全警告

“Safest” 这种绝对词尤其要谨慎。

## YMYL 和 E-E-A-T

可以简单理解：

```text
风险越高
→ Trust 要求越高
→ Expertise 要求更严格
→ 来源要求更高
→ 审阅要求更高
```

但不是：

```text
非 YMYL
→ 不需要 E-E-A-T
```

所有内容都需要可信。

只是高风险内容需要更强证明。

## 内容来源层级

YMYL 更应该重视来源质量。

可以建立内部来源优先级：

| 等级 | 来源 |
| --- | --- |
| A | 政府、监管机构、正式标准、权威医学机构 |
| A | 原始研究、官方法规、官方数据库 |
| B | 专业组织、大学、权威出版机构 |
| B | 高质量系统综述 |
| C | 专业媒体、专家解释 |
| D | 普通博客、论坛、社媒 |
| E | 无来源 AI 摘要、匿名转载 |

高风险 Claim 不要只依赖 D / E 级来源。

## 作者要求

| 风险 | 作者要求 |
| --- | --- |
| 低 | 有实际经验即可 |
| 中 | 主题专家或资深编辑 |
| 高 | 对应专业能力 |
| 极高 | 专业作者 + 专业审阅 |

例如：

```text
显示器亮度解释
→ 技术编辑可以

处方药相互作用
→ 需要医疗专业能力
```

不能把“内容写得像专家”当成真正 Expertise。

## 审阅要求

审阅不是装饰署名。

一个 Reviewer 应该真正检查：

- 关键事实
- 风险 Claim
- 剂量 / 阈值
- 法律或专业边界
- 来源
- 过时信息
- 容易误导的绝对表述

页面可以显示：

```text
Written by
Reviewed by
Last medically / technically reviewed
```

但前提是流程真实存在。

## 绝对词检查

YMYL 页面尤其需要扫描：

```text
always
never
guaranteed
safe
risk-free
cure
prevent
best
100%
```

不是这些词绝对不能出现。

而是：

> **证据强度必须匹配语言强度。**

例如：

```text
This treatment cures...
```

需要非常高等级证据。

很多情况下更合理的是：

```text
may help
is associated with
can reduce risk under
is commonly recommended for
```

## 时效性

YMYL 对过时信息更敏感。

建议给高风险页面建立更新周期。

| 内容 | 检查频率 |
| --- | --- |
| 药物 / 医疗指南 | 高频 |
| 税务 | 法规变化时立即 |
| 金融利率 | 高频 |
| 法律 | 法规变化时 |
| 安全标准 | 标准更新时 |
| 普通概念 | 低频 |

不要通过：

```text
只改 updated 日期
```

伪装更新。

真正更新要检查事实。

## 一套 YMYL QA

| 项目 | 问题 |
| --- | --- |
| Risk | 错误后果有多严重 |
| Author | 作者是否匹配主题 |
| Reviewer | 是否需要专业审阅 |
| Evidence | 高风险 Claim 是否有高质量来源 |
| Freshness | 是否可能过时 |
| Scope | 是否说明适用条件 |
| Safety | 有没有危险操作 |
| Disclosure | 商业利益是否披露 |
| Language | 是否过度承诺 |
| Escalation | 何时应该寻求专业帮助 |

## 风险评分

这不是 Google 官方评分，只用于内部内容治理。

```text
YMYL Risk
=
Harm Severity
×
Actionability
×
Uncertainty
```

每项 1–5 分。

例如：

```text
“如何给显示器调亮度”
Severity 1
Actionability 3
Uncertainty 1
= 3
```

而：

```text
“如何自行调整处方药剂量”
Severity 5
Actionability 5
Uncertainty 5
= 125
```

可以设置内部阈值：

| 分数 | 流程 |
| ---: | --- |
| 1–15 | 普通编辑 |
| 16–40 | 资深编辑复核 |
| 41–75 | 专业审阅 |
| >75 | 高风险，谨慎决定是否发布 |

## SEO 排查

如果一个高风险主题长期表现弱，不要只修改 Title。

先检查：

| 层级 | 排查 |
| --- | --- |
| Intent | 页面类型是否正确 |
| Author | 专业身份是否足够 |
| Source | 来源是否可靠 |
| Claims | 是否过度承诺 |
| Freshness | 是否过时 |
| Reputation | 网站是否有该主题基础 |
| Reviewer | 是否需要审阅 |
| UX | 重要警告是否清楚 |

对于 YMYL 来说：

```text
更多关键词
更多字数
更多 FAQ
```

都不能代替 Trust。

## 常见错误

| 错误 | 为什么危险 |
| --- | --- |
| 用 AI 自动写医疗内容直接发布 | 缺少专业验证 |
| 伪造医生作者 | 欺骗 |
| 把营销 Claim 当科学结论 | 误导 |
| 用论坛回答支持高风险建议 | 来源不足 |
| 使用过时税法 | 现实损失 |
| Affiliate 排名文章隐藏佣金 | 利益冲突 |
| “最佳投资”不讨论风险 | 决策失真 |
| “最安全”没有标准依据 | 绝对 Claim 无证据 |

## 核心优化目标

YMYL 优化不是：

```text
给所有页面加免责声明
```

免责声明不能修复错误内容。

真正目标是：

```text
先判断风险
+
提高作者门槛
+
提高来源等级
+
增加专业审阅
+
控制语言强度
+
明确适用条件
+
持续更新
+
让用户知道什么时候应该找专业人士
```

> **YMYL 的核心是“伤害风险”。错误信息越可能影响健康、钱、安全或重要生活决策，Google 对 Trust 和 E-E-A-T 的要求就越高。真正的优化不是包装权威，而是降低用户因为错误内容做错决定的概率。**
