> Brand 和 Non-brand 混在一起，会让 SEO 增长判断失真。品牌词告诉你“有多少人已经知道你”，Non-brand 更接近“SEO 帮你获取了多少新的搜索需求”。

## 两类 Query

### Brand

包含：

- 品牌名
- 品牌拼写变体
- 产品品牌组合
- 品牌 + Login
- 品牌 + Support

例如：

```text
ZimaSpace
ZimaOS
ZimaBoard support
```

### Non-brand

不依赖品牌认知。

例如：

```text
home server
best NAS OS
local AI server
Plex hardware requirements
```

## 为什么分开

假设：

```text
Organic Clicks +30%
```

看起来 SEO 很好。

但拆开：

| Query | 变化 |
| --- | ---: |
| Brand | +80% |
| Non-brand | -5% |

说明增长主要来自：

```text
品牌需求
```

而不是 Non-brand SEO 扩张。

反过来：

```text
Brand →
Non-brand +40%
```

更能说明：

```text
搜索覆盖正在扩大
```

## Brand 代表什么

Brand Search 通常受到：

- 广告
- PR
- 社媒
- Event
- 产品发布
- 线下曝光
- Word of Mouth

影响。

所以 Brand Organic 不能全部归功于 SEO。

但 SEO 仍然需要保证：

```text
品牌词 SERP
准确
稳定
占据主结果
```

## Non-brand 代表什么

Non-brand 更接近：

```text
需求获取
```

例如：

```text
用户还不知道品牌
→
先搜问题
→
看到你的页面
→
认识品牌
```

这通常是内容 SEO 的核心增长来源。

## 分类方法

最简单：

```text
Query contains Brand Terms
→ Brand

Else
→ Non-brand
```

需要建立品牌词库：

| 类型 | 示例 |
| --- | --- |
| Brand | ZimaSpace |
| Product | ZimaBoard |
| Product | ZimaBlade |
| Misspelling | zimaboardd |
| Domain | zimaspace.com |

不要只匹配一个主品牌名。

## 混合 Query

例如：

```text
ZimaBoard home server
```

通常归：

```text
Brand
```

因为用户已经知道品牌。

如果需要更细，可以拆：

| 类型 | 示例 |
| --- | --- |
| Pure Brand | ZimaSpace |
| Brand + Product | ZimaBoard |
| Brand + Intent | ZimaBoard Plex |
| Non-brand | Plex server |

## 指标表

| 指标 | Brand | Non-brand |
| --- | ---: | ---: |
| Clicks | 8,000 | 20,000 |
| Impressions | 30,000 | 500,000 |
| CTR | 26.7% | 4% |
| Position | 1.8 | 8.5 |

Brand CTR 天然更高。

所以不能直接比较：

```text
Brand CTR 25%
vs
Non-brand CTR 4%
```

然后说 Non-brand 表现差。

## 周报

建议固定输出：

| 类型 | 本周 | 上周 | 变化 |
| --- | ---: | ---: | ---: |
| Brand Clicks | X | Y | % |
| Non-brand Clicks | X | Y | % |
| Brand Impressions | X | Y | % |
| Non-brand Impressions | X | Y | % |

这样能看清 SEO 增长来源。

## Brand 上升

可能来自：

- PR
- 新产品
- Event
- Viral Content
- Paid Campaign
- Social Campaign

这时 SEO 要做的是：

```text
确保品牌 SERP 承接流量
```

而不是把增长全部归因于排名优化。

## Non-brand 上升

通常值得继续拆：

```text
Topic
Page
Query
Country
```

例如：

| Topic | Non-brand Click Growth |
| --- | ---: |
| Local AI | +45% |
| Home Server | +20% |
| Media Server | -5% |

这样才能找到真正增长方向。

## Brand 下滑

先看：

```text
Google Trends
```

如果品牌搜索热度下降，可能是市场问题。

如果 Trend 稳定但 Brand Clicks ↓，检查：

- SERP 被第三方占据
- 官网结果下降
- Knowledge Panel 变化
- Paid Ads 增加
- Title 变化
- Indexing

## Non-brand 下滑

优先查：

- Ranking
- Search Demand
- Intent Shift
- Competitor
- Content Decay
- Core Update
- Cannibalization

这才更接近传统 SEO 诊断。

## Brand Share

可以建立内部指标：

```text
Brand Share
=
Brand Clicks
÷
Total Organic Clicks
```

例如：

```text
Brand 8,000
Total 28,000

Brand Share = 28.6%
```

如果 Brand Share 快速上升，不一定坏，但要判断：

```text
是 Brand 变强
还是 Non-brand 变弱
```

## Non-brand Growth

更适合衡量内容 SEO：

```text
Non-brand Growth
=
Current Non-brand Clicks
-
Previous Non-brand Clicks
```

也可以按：

- Topic
- Directory
- Market

拆分。

## Landing Page

Brand 常落：

- Homepage
- Product
- Login
- Support

Non-brand 常落：

- Blog
- Comparison
- Buying Guide
- Collection

如果 Brand Query 大量落到无关 Blog，可能需要优化站点实体和页面匹配。

## 常见误区

| 误区 | 问题 |
| --- | --- |
| Organic 增长都是 SEO | Brand 可能来自营销 |
| Brand CTR 高代表内容更好 | 品牌认知天然影响 CTR |
| Brand 越少越好 | 品牌需求也很重要 |
| Non-brand 只看总量 | 应拆 Topic |
| 只匹配主品牌名 | 会漏产品品牌词 |

## 核心规范

```text
先建立 Brand Query 词库
→
拆 Brand / Non-brand
→
分别看 Clicks / Impressions
→
Non-brand 再拆 Topic / Page
→
Brand 再结合 Trends 和营销
```

> **Brand 与 Non-brand 分析真正解决的是“增长来自哪里”。SEO 的新增需求能力主要看 Non-brand，而 Brand Search 更适合衡量品牌需求和品牌 SERP 承接能力。**
